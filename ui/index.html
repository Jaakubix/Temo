MovieShelf

Projekt UI aplikacji do osobistej półki filmów — lista, szczegóły, dodawanie z API, lokalizacja seansu i losowanie przez potrząśnięcie.

Ekrany

Nawigacja

  1. Półka → zakładki: Do obejrzenia / Obejrzane / Ulubione
  2. Półka → tap karty → Szczegóły
  3. Półka → FAB „+” → Dodaj / Szukaj (TMDb)
  4. Szczegóły → Edytuj → Edycja (ocena, notatka, status, GPS)
  5. Bottom bar → Movie Shaker (akcelerometr)

Design system

  • Tło #F2F5F8
  • Tekst #15202B
  • Akcent #D97706
  • Status / GPS #0F766E
  • Font brand: Space Grotesk
  • Font UI: Outfit
